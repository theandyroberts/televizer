TELEVIZER

Extension settings

Make the web presentable, only where you want it.

Activation

Click the toolbar icon or press Alt + Shift + T to use Televizer on the current page. That temporary access does not require permanent permission to every website.

Automatically enable everywhere

Make Televizer ready as each ordinary webpage opens. Chrome will ask before granting this broader access.

Automatically enabled websites

Right-click the Televizer toolbar icon on a webpage and choose Automatically enable on this website to add it.

    No websites have permanent access.
